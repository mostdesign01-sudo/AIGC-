# HTML+：AI 时代的工作表达新方式

用浏览器直接打开本目录的 `index.html`（双击或拖进 Chrome / Edge / Safari，`file://` 即可）。无需安装、无需构建、无需网络。单文件，无外链、无字体 CDN。

门前大字 `HTML+`。点「进入课堂」或按 `Enter` / 空格，一步到 P01。课堂里桌面可「改字」，刷新后仍在；演示输出（身份、比较、任务）不入库，刷新或 `R` 回到初始。

## 快捷键

| 键 | 作用 |
|---|---|
| `Enter` / 空格 | 门前：进入课堂 |
| `←` / `PageUp` | 上一页 |
| `→` / 空格 / `PageDown` | 下一页 |
| `S` | 开/关讲稿（口播 / 操作 / 过渡 三行） |
| `E` | 开/关改字（仅桌面；手机 dock 无「改字」入口，也无键盘 `E`） |
| `R` | 重置：清改字、清演示、回 P01 |
| `F` | 全屏 / 退出全屏 |
| `Esc` | 退出讲稿、退出改字 |

编辑焦点内（光标在可改的字里）先 `Esc` 再 `R`：焦点里按 `R` 会键入字母，不会重置。

另外：左栏 / 手机 HUD 六点章首；dock「上一页 / 下一页」；舞台左右 22% 点击翻页（点在卡片、按钮、设备框上不翻）；手机左右滑动翻页（在 T恤、九格、身份按钮上滑不翻页）。

**改字只在桌面。**
