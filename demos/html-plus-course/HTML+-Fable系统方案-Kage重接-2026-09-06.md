## 3. 分批执行清单（Grok 4.6）

每批一个主题、一个 commit（标题 `HTML+ 重接R<n>：<主题>`）、一次 PR 更新；做完跑第 5 节对应项；**不跨批带工作、不碰冻结句、不碰 `data-note`、不改页序**。顺序 R0 → R1 → R2 → R3 → R4 → R5；R2 / R3 / R4 彼此不依赖，R0 之后可并行，但 PR 分开。

- 七条冻结句文本、`data-frozen` 节点内容、`FROZEN` 常量；复制永远从常量。
- `data-note` 二十条；20 页顺序；`chStarts`；六章名；四动作词与顺序；三案名与四拍词。

### 4.4 与「不搬 Three.js」的边界

- 空间感来自三件事：**机位不同的同图裁切**（章封面）、**近景压边**（手 / 指尖贴框外侧）、**留白**（讲解页无手无纹）。不需要 WebGL。
- 允许的动：`transform / opacity` 过渡 300–900ms；hover 三档位移；四拍瞬态。不允许：滚动驱动相机、逐帧、粒子、雨、叶、月。
- 允许的层：`.cut` 每页 ≤ 3；`<canvas>` 仅现有 grain 一处；`mix-blend-mode` 只用 `screen`（黑场）/ `multiply`（白底）。
