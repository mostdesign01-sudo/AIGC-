# Html大法 — 得物AI公开课

这就是课本身。不是 T 恤配置器，不是产品预览，不是作品集。

一份 HTML，给主讲把飞书「Html大法 — 得物AI公开课」整堂走完：

**00 立课脊 → 01 立三招 → 02 进三个案例 → 03 布置作业。**

课脊：**一份 HTML，N 种形态 / One HTML. Many forms.**

## 怎么打开

不需要安装，不需要构建。

1. 用浏览器打开本目录里的 `index.html`
2. 本地路径即可，例如：

```
file:///…/demos/html-dafa-course/index.html
```

双击文件，或把文件拖进 Chrome / Edge / Safari。`file://` 必须能用。

### 02 三个房间

1. **一套 HTML，多个对象** — 11周年 T恤、物流箱、奖杯、防伪物料。HTML 不是替代服装设计，而是把静态稿升级成能被观察和比较的沟通工具。
2. **网页里 9 款 NONO** — 对象多时，HTML 是统一管理和比较资产的操作台。
3. **HTML + 视频插件** — 《得物业务知多少》VOL.06，传播招：给已有 HTML 加入出现时间、转场、声音和自动播放。

## 键盘

- `←` `→` 或空格：沿课往前 / 往后（案例房间里则一间一间走）
- 点左侧 `00 / 01 / 02 / 03`：跳章
- `F`：全屏
- `S`：讲稿
- `Esc`：关讲稿，或从房间回课
