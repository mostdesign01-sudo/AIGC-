02 / 案例 01 · 一套 HTML 编辑器复用多个对象

HTML 不是替代服装设计，而是把静态设计稿升级成能被观察和比较的沟通工具。

课上只讲这件事。下面是示意，不是把编辑器打开。

示意三步 · 拖 / 换标 / 看面料
  1. 1 · 拖动把一件静态稿转起来，先观察。
  2. 2 · 换贴标袖标开 / 关，两态才能比较。
  3. 3 · 看面料针织、油墨、箱板——证据要被看清。

同一套底座接着复用：物流箱 · 奖杯 AR · 防伪变色油墨
