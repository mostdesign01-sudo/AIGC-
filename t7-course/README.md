# 走进 HTML：一份内容，三种交付

> 得物 · 互联宝地 T7 · 沉浸式 WebGL 课程网站

以"走进得物 T7 大楼"为叙事线索的单页三维课程体验：用户从大楼外部的电影感远景开始，
通过滚动连续控制摄像机，穿过广场与悬浮列车、进入玻璃门厅，沿扶梯、观光电梯、中庭坡道、
台阶走廊与光井楼梯在同一栋建筑内逐层上行，依次经过七个课程空间，最终抵达屋顶完成作业发布。

**一镜到底 · 一栋大楼 · 七个空间 · 三种交付。**

## 快速启动

无构建步骤、无外部网络依赖（three.js 已本地化）。任何静态服务器均可运行：

```bash
cd t7-course
python3 -m http.server 8080
# 打开 http://localhost:8080
```

## 讲师操作

| 操作 | 效果 |
|---|---|
| 鼠标滚轮 / 触控板 | 连续推进课程（镜头随滚动前进） |
| `PageDown` / `→` | 下一章节（镜头真实穿行，不跳切） |
| `PageUp` / `←` | 回到本章锚点 / 上一章节 |
| `Home` / 顶部按钮 | 一键返回首屏 |
| `End` | 直达屋顶终幕 |
| 右侧圆点 | 点击直达任意章节 |
| `#ch=5` 或 `#p=0.66` URL | 深链直达章节 / 进度（`&auto` 跳过加载页），适合上课前预置 |

互动实验室（第 5 章）：按住模型拖动旋转；鼠标悬停模型时滚轮为缩放；
左下面板切换案例与配色/状态。放映厅（第 6 章）：底部面板播放 / 暂停 / 重新播放 / 全屏。

HUD 右上：声音开关（WebAudio 合成环境音与列车声，默认关）、画质 高/低、动效 全/少、返回顶部。
移动端自动进入低画质；`prefers-reduced-motion` 自动开启减少动画。

├── index.html            # 单页入口（HUD / 章节文字层 / 面板）

│   ├── interiors.js      # 七个室内空间与竖向交通
