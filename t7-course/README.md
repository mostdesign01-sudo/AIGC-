# 走进 HTML：一份内容，三种交付

> 得物 · 互联宝地 T7 · 滚动课程网站

走进 T7：**只有直梯，没有扶手电梯**。设计部与 CEO 都在 **19F**。
静帧走楼，底部一条克莱因蓝文案；PPT、产品、视频嵌进画面里的屏幕。

## 快速启动

```bash
cd t7-course
python3 -m http.server 8080
```

## 讲师操作

| 操作 | 效果 |
|---|---|
| 滚轮 / 触控板 | 连续推进 |
| `PageDown` / `→` | 下一章节 |
| `PageUp` / `←` | 本章锚点 / 上一章 |
| `Home` | 首屏 |
| 右侧圆点 | 跳章 |
| `#ch=5` 或 `#p=0.69` | 深链（`&auto` 跳过加载页） |

19F 工位：拖转产品、换色/开箱；若放入真实互动包，在工位屏里直接操作。
19F 放映：播放 / 重播 / 全屏。
