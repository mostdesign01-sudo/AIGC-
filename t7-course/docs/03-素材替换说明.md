# 素材替换说明

所有可替换素材位于 `assets/`，替换后刷新即可，无需构建。

## 1. 得物 LOGO

| 文件 | 用途 |
|---|---|
| `assets/brand/dewu-logo-white.png` | 备用白字 |
| `assets/brand/dewu-logo-app.png` | favicon / HUD / 加载页 |

请用官方文件，不要用 AI 重绘。

## 2. 电影静帧

`assets/stills/*.jpg`，统一 1536×864。当前序列：

| 文件 | 空间 |

| `01-exterior.jpg` | 广场夜景：铁锈红陶板塔楼落在干燥铺装上 |

| `05-meeting.jpg` | 19F 玻璃会议室（主屏为 PPT 槽） |

互动叠层坐标在 `js/config.js` 的 `DIEGETIC`（图内 0–1 UV）。换图后若屏幕位置变了，改这三项即可。

## 3. 产品演示（19F 工位屏）

1. 把 `POIZON_统一产品互动演示_*.zip` 解压到 `assets/products/`；
2. 按 `assets/products/README.md` 改 `manifest.json` 的 `src`；
3. 刷新：工位显示器改为 iframe 真实页面。

没有真实包时，工位屏使用 `js/lab.js` 的四个程序化案例。

## 4. HyperFrames 视频

替换 `assets/video/hyperframes-demo.mp4`。重新生成：`python3 tools/make_video.py`。

## 5. 文案

- 底部克莱因蓝条：`js/content.js`
- 会议室 PPT：`js/slides.js`
- 章节楼层：`js/config.js` 的 `CHAPTERS`

## 6. 部署

`python3 -m http.server 8080`。单文件离线版：`python3 tools/build_singlefile.py`。
