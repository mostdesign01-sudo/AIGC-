# 素材替换说明

所有可替换素材位于 `assets/`，替换后刷新页面即可生效，无需构建。

## 1. 得物 LOGO

| 文件 | 用途 | 要求 |
|---|---|---|
| `assets/brand/dewu-logo-white.png` | 大楼正/背面发光字、屋顶品牌 | 白色字形 + 透明底 PNG，建议 ≥ 750×434（当前按 375:217 比例排版，若比例变化请同步修改 `js/building.js` 中 `logoW / logoH`） |
| `assets/brand/dewu-logo-app.png` | 页面 favicon、HUD、加载页 | 方形圆角 App 图标，≥ 120×120 |

> 请始终使用官方 LOGO 文件，不要用 AI 重新生成。

## 2. HyperFrames 视频（放映厅银幕）

替换 `assets/video/hyperframes-demo.mp4` 即可。要求：

- H.264 + AAC 的 mp4（`-movflags +faststart` 便于秒开）；
- 建议 16:9（银幕面板为 10.2m × 5.75m，非 16:9 会被拉伸）；
- 站点默认静音自动播放（浏览器策略），观众点击"播放/全屏"后有声。

重新生成内置演示视频：`python3 tools/make_video.py`（依赖 Pillow + ffmpeg）。

## 3. 课程文字内容

- 章节标题与讲述文案：`js/content.js`（纯 HTML 字符串，按章节排列）；
- 大厅媒体墙 / 信息大厅屏幕 / 实验室背景屏 / 屋顶光柱等三维屏幕文案：
  `js/interiors.js` 中各 `makeScreen(...)` 的绘制函数（Canvas 排版，中文直接可用）；
- 会议室 HTML PPT 五页内容：`js/slides.js` 的 `SLIDES` 数组（每页一个 `draw` 函数，
  `b` 参数为页内逐步展开进度 0–1）。

## 4. 互动实验室案例

`js/lab.js` 中每个案例是一个独立的构建函数（`buildShirt / buildBox / buildTrophy / buildNono`），
返回 `{ group, name, en, tip, variants, applyVariant, update? }`。
新增案例：编写构建函数后加入 `cases` 数组，并在 `js/interiors.js` 的 `pedPos` 中增加展台位置。
若要接入真实产品模型（GLB），可在构建函数内用 `GLTFLoader`（需将 loader 一并本地化到
`assets/vendor/`），保持返回结构不变即可复用拖拽/缩放/变体逻辑。

## 5. 品牌色与视觉参数

- 全局色板：`js/config.js` 的 `COLORS`（极光蓝 `0x01c2c3`）与 `css/main.css` 的 `:root` 变量；
- 建筑尺寸 / 楼层高：`js/config.js` 的 `B`；
- 镜头路径：`js/cameraPath.js` 的 `KEYS`（`t` 为滚动进度，`pos` 机位，`look` 注视点）；
  修改室内布局后请同步校对相应关键帧。

## 6. 图转 3D（Tripo / TRELLIS / Hunyuan3D）接入

站点内置了外部建筑模型接入口：

1. 用 [Tripo Studio](https://studio.tripo3d.ai)（网页版，需注册，有免费额度）上传 T7 真实照片，
   生成模型后导出 **GLB** 格式；也可用开源的
   [TRELLIS](https://github.com/microsoft/TRELLIS) / [Hunyuan3D-2.1](https://github.com/tencent-hunyuan/hunyuan3d-2.1)
   在带 CUDA GPU 的机器上本地生成；
2. 把文件命名为 `t7-exterior.glb`，放到 `assets/models/` 目录（目录不存在则新建）；
3. 刷新页面：**外景章节（第 1 章）会自动显示该模型**（自动按主楼高度缩放、落地居中），
   镜头进入建筑前自动切回程序化楼体，保证入口开门与室内叙事不受影响。

注意：生成式模型常见融化边缘与结构粘连（任务书明确禁止直接用于最终建筑），
该入口主要用于对比评估或经三维软件修复后的模型；课程主体默认使用硬表面程序化楼体。
互动实验室的产品模型（T 恤 / 盲盒等单体物件）更适合图转 3D，生成 GLB 后可在
`js/lab.js` 中用 `gltfloader`（已本地化）加载替换。

## 7. 部署

纯静态目录，任意静态托管（Nginx / 对象存储 / GitHub Pages）直接可用；
不依赖登录态或 OJO 平台。本地演示：`python3 -m http.server 8080`。
