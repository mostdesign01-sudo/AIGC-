## 二、完整镜头路径（单条连续时间轴，无跳切）

1. **远景**（0）：广场东南侧仰视 T7 全貌，列车沿环形轨道穿行，HTML 字从楼后耸出；
2. **前推**（0.03–0.11）：穿过广场树阵与轨道下方，沿极光蓝地面导引线对准中央入口；
3. **入口**（0.13–0.16）：穿过雨棚，玻璃滑门在镜头到达时开启，真实穿门进入门厅；
4. **大厅**（0.16–0.24）：挑高大厅内前行，正对媒体墙，两侧案例屏与导视屏；
5. **扶梯**（0.24–0.29）：乘扶梯连续上行穿过大厅天花开洞，抵达 3F；
6. **信息大厅**（0.29–0.40）：沿展廊横移，逐屏阅览四块信息屏与长条清单屏；
7. **观光电梯**（0.41–0.47）：电梯门开合，玻璃轿厢竖直上行，井道楼层光环掠过，6F 到站提示音；
8. **会议层**（0.47–0.56）：走向主屏，滚动驱动 HTML PPT 五页逐步展开；
9. **中庭坡道**（0.56–0.60）：圆形砖筒中庭内沿螺旋坡道盘旋一整圈上行至 9F；
10. **实验室**（0.61–0.70）：弧形绕行四座展台，互动窗口开启；
11. **台阶走廊**（0.71–0.74）：影院式入场坡道，极光蓝地灯线 + HYPERFRAMES 海报灯箱；
12. **放映厅**（0.74–0.85）：从最高排沿中央走道推向银幕，视频自动开演；
13. **光井楼梯**（0.85–0.875）：银幕旁出口进入光井，沿垂直极光蓝导引光线上升，破顶而出；
14. **屋顶**（0.88–1.0）：开阔平台，回望三个作业光柱，终幕拉远——城市灯光、列车、HTML 字。

## 三、动效规范

- 滚动进度与镜头一一对应；停止滚动镜头平稳停驻（全局阻尼 + 限速）；
- 章节跳转不瞬移：以受限速度沿同一条路径穿行；
- 所有转场使用真实空间构件（门 / 扶梯 / 电梯 / 坡道 / 走廊 / 光井），无透明化、无溶解、无黑屏；
- 克制的辉光、环境雾、灯光呼吸、体积光暗示（放映机光束）、接触阴影由 AO 近似与暗部材质承担；
- 减少动画模式：列车减速、灯光呼吸停止、滚动阻尼收紧；
- 低性能模式：像素比 1、雾密度提高（缩短可视距离）。

## 四、建筑与列车建模要点

- **建筑**：盒体硬表面 + 世界尺度 UV（砖纹密度全楼一致）；幕墙为不透明自发光窗格材质
  （高金属度反射 + 楼层灯光贴图），从根本上避免透明排序错误与模糊边缘；
  裙房为空壳（大厅位于其内部），塔楼与翼楼外壳自 3F 起（底部让位给挑高大厅）；
  女儿墙为环形矮墙，屋面真实露出。
- **列车**：4 节编组（头/中/中/尾），车头三段渐缩整流罩 + 倾斜驾驶舱前窗 + 头灯/尾灯，
  分段车窗带窗间柱、双开车门带门框与门窗、底盘 + 抱轨悬浮橇 + 磁体发光面、
  车顶空调与走线槽、第二节受电弓、车身编号 DEWU · T7-0x、裙边极光蓝识别灯带；
  匀速带微小低频起伏，减少动画模式下减速运行。
